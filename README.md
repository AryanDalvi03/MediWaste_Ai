## 📖 Overview

MediWaste AI is an intelligent healthcare waste management platform designed to assist hospitals and healthcare facilities in accurately classifying biomedical waste using Artificial Intelligence.

The system aims to improve waste segregation, reduce environmental impact, enhance operational efficiency, and support compliance with biomedical waste management regulations.

---

## 🚀 Problem Statement

Improper segregation of biomedical waste can lead to:

* Environmental pollution
* Increased disposal costs
* Health risks for healthcare workers
* Regulatory compliance issues
* Inefficient waste handling processes

MediWaste AI helps address these challenges through automated AI-based waste classification and decision support.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/AryanDalvi03/MediWaste_Ai.git
cd MediWaste_Ai
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
uvicorn main:app --reload
```
